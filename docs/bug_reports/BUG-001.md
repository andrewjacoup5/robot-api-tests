## Description
`POST /posts` returns 201 with the new post, but the post is not stored.

## Steps to Reproduce
1. Send `POST /posts` with `{"title": "foo", "body": "bar", "userId": 1}`. The response is 201 with `id: 101`.
2. Send `GET /posts/101`.

## Expected Result
200 with the created post.

## Actual Result
404 Not Found.
